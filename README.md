# 撃つと浸水して沈む船 — Godot再現 (Boat Sink)

GTA6比較動画の写真「船底に発砲 → 水漏れ → 船内が水で満たされ、傾いて乗っていられなくなる」を
Godot 4.6.3 / GDScript で再現したプロトタイプ。NetQuest等の既存プロジェクトとは無関係の独立プロジェクト。

## 仕組み (写真の挙動の再現方法)

水を全流体シミュレーションせず、数値モデルで成立させている:

1. **被弾で穴を記録** — レイキャストの命中点・法線を船体ローカル座標で保存し、黒い穴+焦げ縁を表示。
2. **穴が水面より下のときだけ浸水** — 穴のワールド高さと波高を比べ、深い穴ほど流入量が多い。
   水面上の穴は浸水しない (テストで検証済み)。
3. **浸水量で浮力が落ち、荷重が増える** — RigidBody3D の船体5点で浮力を計算し、
   浸水率に応じて浮力係数を下げ、さらに「溜まった水の重さ」を穴の平均位置に
   下向き荷重として加えるので、**穴を開けた側へ傾きながら**沈む。
4. **見た目の連動** — 船内の水面メッシュが浸水率で上昇し、穴の内側に泡が出る。
   HUD に穴の数・浸水%・状態 (浮いている/浸水中/もう乗っていられない/沈没…) を表示。

## v2 リアリズム改修 (2026-11-20)

「よりリアルな世界に。Webでできる最高峰の画質で」という要望への改修。

- **船体を Blender 製モデルに置き換え** — `tools/build_boat_model.py` (Blender 4.5) で
  断面ステーションからロフトした船体 (6.4m × 2.3m): チャイン下は濃色の船底塗装、
  白いトップサイド、インナーフロア/内張り、ガンネルキャップ、船首デッキ+オレンジ
  ハッチ、センターコンソール (着色風防・ステアリング)、ティール色クッションの
  ベンチ×2、木箱、クーラー、釣り竿×2、金属製バウレール、クリート、赤/緑の航海灯、
  船外機。`assets/boat.obj` + `boat.mtl` はテキスト形式 (313KB) なので GitHub の
  スナップショット push にそのまま載る。Godot 側ではサーフェス名ごとに PBR
  マテリアルを上書き (ジェルコートは NoiseTexture2D で粗さに微細なムラ、
  レールは金属 0.9/粗さ 0.3、風防は半透明、航海灯は発光)。
- **水面はカスタムシェーダー** — 3つの方向性サイン波の和で頂点変位+法線を計算し、
  フレネルで深い/浅いターコイズを混合、太陽のグリントと高周波リップルを追加。
  **浮力側の `BoatBody.water_height_at()` は同じ3波の和を同じ時刻
  (物理クロックをシェーダーの `wave_time` に供給) で計算する**ので、見た目の
  波と浮き沈みが一致する。船体まわりには泡の輪 (ラジアルテクスチャの平面が
  船の位置・向き・波高に追随)、漂う泡パッチも追加。
- **世界のドレッシング** — 遠景の低い島影×4、遠景の同型ボート×1 (波で揺れる)、
  柔らかいビルボード雲×6。環境は ACES トーンマップ、控えめなグロー、軽い霧、
  太陽影あり。
- **人物も作り直し** — 手足と胴を CapsuleMesh 化し、肌マテリアルの粗さを調整。

### v2 の検証

- ヘッドレス物理テスト: **全項目 PASS (テスト側の許容値変更なし)**。
  新しい波でも idle 浮上 (傾き 5.1°)、水面上の穴は浸水 0、船底3発で12秒後に
  浸水 83.9%・傾斜 18.4°、最終的に沈没、リセットで復帰。
- Xvfb スクリーンショットで構図・配色を2周確認 (1周目で水面の白飛びを
  シェーダーの色/スペキュラとグローで修正)。
- Web 書き出し成功 (pck 3.0MB)。

### 正直な限界

- 描画は **GL Compatibility (Web) の天井**が上限。Forward+ 専用の
  SDFGI / SSAO / SSR / ボリューメトリックフォグは Web 版では使えず、
  グローと霧も Compatibility では best-effort。フォトリアルな水の屈折・
  反射プローブや高密度メッシュは iPhone の WebGL2 性能との兼ね合いもあり
  入れていない。「Webでできる最高峰」はこの範囲内での最適化という意味。

## 操作

- クリック / タップ: その場所を撃つ (船底・水面下の側面が効く)
- ドラッグ: カメラ回転 / ホイール: ズーム / R: リセット
- ボタン: 「船底を撃つ」「右舷を撃つ」(確実に沈めたいとき用)

- ヘッドレス物理テスト `tests/test_scene.tscn`: 全項目 PASS

## v2.1 (2026-11-20) — 「打った場所に当たらない」の修正

実機プレイでの指摘を受けて修正。原因は当たり判定が船の形と違う大きな箱だったこと:
上から撃つとレイが箱の上面に先に当たり、狙った舷側ではなく箱の上面に穴が開いて見えた。

- 射撃の当たり判定を Blender 製の見た目メッシュそのもの (凹面コリジョン) に変更。
  狙ったピクセルの「見えている面」に穴が開く。コンソール等の箱より上の部分にも当たる
- HUD (照準・パネル・ラベル) がタップを奪わないよう mouse_filter を全て IGNORE に
  (ボタンだけ有効)。タップ判定も累積移動量→押した位置からの距離 (20px) に変更し、
  指の微振動でタップが回転扱いになるのを防止
- 検証: ヘッドレスのレイ命中テスト (狙点と穴の距離・上面に開かない・コンソール命中)
  + Xvfb での実タップイベント再現 (船尾・コンソールとも発砲成功)。
  ヘッドレス環境はマウスイベント自体を落とすため、タップ検証は Xvfb 側でのみ実施
